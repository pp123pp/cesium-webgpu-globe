# M4 — V0.4 cloud shadows and terrestrial lighting

**Prerequisite:** stable global clouds (M3) and sky/solar illumination (M2).

## Tasks

1. Determine geodetic cloud-shadow projection using the same solar direction and cloud field as M3.
2. Render moving shadows onto the globe ellipsoid and real Terrain, aligned to WGS84 and terrain height.
3. Couple shadow opacity with terrain solar direct lighting; support soft penumbra and appropriate cloud transmittance.
4. Approximate reduction in sky ambient irradiance from cloud cover, without a complete real-time GI solution.
5. Verify altitude / sun angle / time changes and continuity across terrain tiles, including orbital views.
6. Capture A14–A15 and WebGL regression.

## Progress — 2026-11-06

Core implementation is integrated into `main` through `1518222`; M4 is not yet declared complete. [Ellipsoid evidence](../coordination/evidence/M4/ellipsoid-cloud-shadows/README.md) and [terrain evidence](../coordination/evidence/M4/terrain-cloud-shadows/README.md) retain the original physical Intel Xe-LPG reports and source/bundle provenance, rather than certifying a new final-HEAD run.

| Task | Implemented / verified | Remaining acceptance |
| --- | --- | --- |
| 1. Geodetic projection | WGS84 cloud-shell integration shares the M3 density field and solar direction. | Included in final A14 visual review. |
| 2. Ellipsoid and Terrain receivers | Both paths implemented; moving shadows checked on ellipsoid, deterministic terrain meshes and live elevation/imagery. | Final user visual confirmation. |
| 3. Direct lighting / transmittance | Cloud optical depth attenuates direct sunlight with continuous transmittance. | Soft-penumbra acceptance is unresolved; current sampling uses a single solar direction, without explicit finite-Sun angular sampling. |

The demo includes native Animation/Timeline controls, unbounded forward/reverse playback, reset and viewer-resize handling. The existing evidence is single-GPU and does not measure frame cost. M5 profiling has not started; this status update adds no performance gate or new implementation scope.

## Scope boundary

Cloud shadows on 3D Tiles/BIM are expressly postponed to M6. No need to implement a universal scene shadow system.

## Parallelism

Geo shadow mathematics and representative test fixtures may be parallel; **Globe shader binding and terrain lighting integration are single-owner.**
