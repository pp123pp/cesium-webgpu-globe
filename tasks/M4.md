# M4 — V0.4 cloud shadows and terrestrial lighting

**Prerequisite:** stable global clouds (M3) and sky/solar illumination (M2).

## Tasks
1. Determine geodetic cloud-shadow projection using the same solar direction and cloud field as M3.
2. Render moving shadows onto the globe ellipsoid and real Terrain, aligned to WGS84 and terrain height.
3. Couple shadow opacity with terrain solar direct lighting; support soft penumbra and appropriate cloud transmittance.
4. Approximate reduction in sky ambient irradiance from cloud cover, without a complete real-time GI solution.
5. Verify altitude / sun angle / time changes and continuity across terrain tiles, including orbital views.
6. Capture A14–A15 and WebGL regression.

## Scope boundary
Cloud shadows on 3D Tiles/BIM are expressly postponed to M6. No need to implement a universal scene shadow system.

## Parallelism
Geo shadow mathematics and representative test fixtures may be parallel; **Globe shader binding and terrain lighting integration are single-owner.**
