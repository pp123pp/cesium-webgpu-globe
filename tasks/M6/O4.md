# M6.O4 — 展示型潮汐与完整时间行为

> 状态：待实施。所属里程碑：M6 全球海洋；完整水下留在 O7。
> 入口：[M6 总任务](../M6.md) · [主计划](../../docs/OCEAN_PLAN.md) · [设计规格](../../docs/superpowers/specs/2026-11-06-m6-global-ocean-design.md)
> 验收：[M6 验收](../../docs/M6_ACCEPTANCE.md) · [状态](../../coordination/M6-STATUS.md) · [AI 交接](../../coordination/M6-AI-START.md)

## 目标与边界

让海面基准水位按人工设定的幅度、周期和相位变化，并使全部海洋动画服从 Cesium 时间轴。
这是展示型潮汐，不是全球潮汐预测；不接入天文分潮、风暴增水、真实天气或海流预报。
O4 负责水位、波相位和历史状态的时间协议；岸线涨退潮效果由 O5/O6 使用同一水位完成。
单主相机、SCENE3D、桌面物理 WebGPU；既有 WebGL 行为保持不变。

## O4-01 — 冻结可重现的潮位与时间输入

- [ ] **产出：** 时间状态表、展示潮位模块、配置错误行为和最小数值证据。
- [ ] 明确潮位参考高程、幅度、正周期、相位、参考历元和单位；基准由 O0 规定。
- [ ] 用绝对 Cesium 时刻求展示潮位；默认采用可说明的周期函数，幅度为零时严格退化为恒定水位。
- [ ] 区分正常前进、暂停、倒播、跳时、首次进入和配置变更；跳时判据与重置代次可观察。
- [ ] 用 `JulianDate` 的真实方法计算时间差；长时间运行和大日期偏移不得把巨大绝对秒数直接送入低精度相位。
- [ ] 波动、潮位和太阳/天空使用同一帧时刻；空间重定位与时间跳变分别标记，避免误用旧历史。
- [ ] **检查：** 固定时刻的重复求值一致；暂停重复渲染、一个周期首尾、零幅度和非法周期有明确结果。
- [ ] **退出：** 同一场景配置与时刻可恢复同一潮位及解析波相位，且不依赖机器墙钟或帧率。

## O4-02 — 把潮位接入曲面、查询与垂直基准

- [ ] **产出：** 所有水位消费者一致的接入和一份垂直基准核对表。
- [ ] 将潮位加到海面参考高程，FFT 位移仍作为波动分量；沿当地椭球 Up 作用，不能沿全球 Y 轴平移。
- [ ] 统一曲面渲染、水面高度查询、深度合成和相机相对水位；每帧只发布一份有效潮位。
- [ ] 明确水面、terrain 与后续 bathymetry 的垂直转换责任；未知基准不得默认为零偏差。
- [ ] 固定海洋分类与当前潮位下的干湿范围分开；潮位变化不能把全部低于水位的内陆洼地变成海洋。
- [ ] 保留有海洋连通性的潮间带扩展范围；O4 不以扩大固定水体掩码代替 O5/O6 的岸线判定。
- [ ] **检查：** 不同纬度、日期变更线两侧和局部原点重置前后，潮位高程与查询一致且无方向翻转。
- [ ] **检查：** 同一参考基准上的已知底高程得到正确水深符号；缺失基准通过状态报告暴露。
- [ ] **退出：** 所有下游读取同一潮位，没有双重叠加潮位或相机高度与渲染水线相互矛盾。

## O4-03 — 管理泡沫等时间历史

- [ ] **产出：** 每种历史资源的前进、暂停、倒播、跳时与重建策略，以及有界恢复实现。
- [ ] 审计 Tidewater `src/ocean/OceanFFT.js` 的 GPU 累积泡沫；不能把解析波相位可倒播误当作泡沫可逆。
- [ ] 正常前进只给积分器有限的非负步长；大时间差触发重置/有界重建，不循环追算整段历史。
- [ ] 倒播允许解析波与潮位直接求值，泡沫等历史按已声明策略重建、淡入或简化；禁止负步长积分。
- [ ] 跳时、海况修改和空间历史失效时清除不兼容状态；记录原因并让效果在有界成本内恢复。
- [ ] 暂停时停止历史演化与依赖时间的淡入；不得使用 `performance.now()` 或渲染帧数继续推进海洋动画。
- [ ] 暂停时仍允许资源加载和相机移动；若新区域没有历史，使用确定的初始化状态，不伪装历史连续。
- [ ] 明确大倍率播放的工作量上限、降级结果和日志；控制项的参数边界需有依据，不能掩盖错误。
- [ ] **检查：** 暂停后连续渲染、前跳/后跳、正负倍率切换和相机瞬移时无 NaN、爆亮、陈旧泡沫拖影。
- [ ] **退出：** 时间历史策略可解释、可测，任意操作不会提交巨大或负积分步长，也不会无限追帧。

## O4-04 — 完成时间轴可操作演示与交接

- [ ] **产出：** 可重复时间脚本、幅度/周期/相位控制、证据清单和 O5/O6 的潮位输入说明。
- [ ] 控制面板明确写“展示型潮汐”；支持静水位、周期变化、暂停、倍速、倒播和跳转到指定时刻。
- [ ] 把固定相机与时刻序列写入检查夹具；确认近景、远景过渡和太阳反射使用同一时刻。

- [ ] 聚焦数值检查合并执行一次；相关渲染改动稳定后再做一次必要物理 GPU 检查。
- [ ] **检查：** 拍摄前记录源码版本、bundle、GPU 适配器、参数和数据状态；没有物理 GPU 则记 blocked/unverified。
- [ ] **退出：** 时间/潮位用例通过或具体阻塞已登记，O5 能在不自建时钟的条件下消费当前水位。

## 风险与回退

- 高倍率、倒播和跳时无法还原耗散历史：保留解析海面并重建历史，明确记录视觉变化。
- datum 不一致会让潮间带或水深失真：阻塞高精度近岸，不能靠随意调海平面掩盖。
- 潮位只改变海面高程并不自动产生正确岸线：O5/O6 尚未完成的效果必须标为未实现。
- M5 的欠项仍属于 M5 追踪，不能因本阶段通过而关闭；直接影响时间或资源的项应关联阻塞。
