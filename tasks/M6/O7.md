## 目标与边界

在已有全球海洋、水上光学、展示潮汐和代表近岸效果之上，最后接入完整水下及穿越水线体验。
完整范围包含水下介质、动态水线/半浸视图、海面背面、透射/全反射近似、水下光照与海底显示。
效果按数据有效范围与画质预算分级；不增加生物、船只交互、声学、物理潜水或真实海洋预测。
完成后给出 M6 全流程证据；原 3D Tiles/BIM 工作已顺延为 M7，不在此实现。

## O7-01 — 球面水体分类与任意姿态水线

- [ ] **产出：** 真实海域内的相机/像素介质判定、动态水线及半浸视图。
- [ ] 从固定海洋分类、连通干湿范围和当前动态水面共同判定水体；不能只用相机椭球高度小于零。
- [ ] 复核 O1 的椭球内通路与 terrain/海底遮挡，保证进入海水不会看到默认实心椭球或穿透陆地。
- [ ] 将水面查询与渲染曲面统一到 O0 当地坐标；海面高程包含 O4 潮位与 O6 有效波动。
- [ ] 用实际视线/近裁面及水面相交处理部分浸没；不能假定屏幕水线是水平线或逐列只交一次。
- [ ] 处理 camera roll、斜向穿越、掠水角、局部原点重置和数值容差，避免水线抖动或整屏闪切。
- [ ] 当海岸/水深数据缺失时声明水体有效域和回退，不能把地下、内陆洼地或相机近地误判为水下。
- [ ] **检查：** 不同纬度、日期变更线、任意 roll 和潮位两端，水上/半浸/水下分类与曲面一致。
- [ ] **退出：** 水线由实际姿态与动态曲面决定，且相机穿越时没有海陆分类错误或椭球内黑屏。

## O7-02 — 完整水下光学与海面背面

- [ ] **产出：** 与生产深度/HDR 兼容的水下介质、背面海面、海底光照和质量档。
- [ ] 按有效水路径长度合成吸收与散射；用水深/浑浊度参数控制，不用全屏固定蓝雾替代距离响应。
- [ ] 处理向上看海面时的透射、折射、Snell 窗和全反射近似，水上天空/太阳/云与水下表观连续。
- [ ] 处理动态波面背面、岸浪和水线附近的遮挡；不重复绘制两层互相打架的水面深度。
- [ ] 将太阳/天空照明和有界焦散/光束近似应用到有效海底/水域，记录哪些效果属于可调近似。
- [ ] 当海底未知时提供合理深水外观并暴露数据空白，不能生成伪造精确海底来满足验收。
- [ ] 保持空气段与水段合成边界清晰，避免既有 aerial perspective/云透射在水路径上重复叠加。
- [ ] 保持水下与水上相同的 HDR/曝光/色调映射约定；关闭海洋后恢复既有场景行为。
- [ ] **检查：** 浅水看底、深水、向上看太阳、斜穿波面、岸边半浸和昼夜变化无爆亮、泄漏或重复雾。
- [ ] **退出：** 介质和海面背面的主要观看方向都成立，允许的近似/质量差异明确且可复现。

## 风险与回退

- 平面世界水线假设会在高纬或 roll 下失效：必须按实际姿态重建；不以限制相机姿态隐去问题。
- 屏幕空间折射/焦散存在视域限制：按批准近似回退并记录，不默认升级为 SSR 或全路径追踪。
- 海底数据精度决定可见细节：分开报告渲染能力、数据覆盖与精度，未知区域不得标成高精通过。
- 未完成 M5 的稳定性/生命周期/性能项仍保留；仅被 M6 证据实际覆盖的项才可由负责人判断关闭。
