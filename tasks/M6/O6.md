# M6.O6 — 近岸浅化、碎浪、泡沫、湿沙与涨退潮

> 状态：待实施。所属里程碑：M6 全球海洋；完整水下留在最后 O7。
> 按需参考：[总体路线](../../docs/OCEAN_PLAN.md) · [合同](../../docs/M6_OCEAN_CONTRACTS.md)
> 验收：[M6 验收](../../docs/M6_ACCEPTANCE.md) · [当前任务与状态](../../coordination/M6-STATUS.md)

## 目标与边界

先在有可靠数据的代表岸型完成浅化、波向变化、碎浪/泡沫和湿沙，随后验证全球数据驱动回退。
展示型潮汐推动连通潮间带的涨退；它不等价于流体求解、侵蚀预测或真实潮汐预报。
只实现海洋；船只浮力、尾流、人物入水、河湖与交互物体均不属于本阶段。
本阶段是正式效果与性能验收节点，完整水下视角仍不得提前宣告完成。

## 前置与执行约束

- [ ] O3 的开阔海效果与性能基线、O4 的时间/潮位和 O5 的近岸数据/光学接口已交接。
- [ ] O0 的当地坐标、移动域、预算、重置和资源协议已冻结；检查实际接口后实施。
- [ ] [M6 验收](../../docs/M6_ACCEPTANCE.md) 已列出代表岸型、目标硬件和本阶段预算来源。
- [ ] M5 欠项保留追踪，仅直接破坏近岸合成、连续性或资源释放者作为本阶段阻塞。

Tidewater 是算法与视觉参考，不能原样假定为全球岸线方案：`src/world/ShoreField.js` 按当地水深
预烘传播 arrival/exposure；`src/ocean/ShoreWaves.js` 使用固定沙滩坡度，`src/ocean/ShoreSim.js`
维护固定局部历史场。它们都需要适配当前潮位、真实局部地形和相机移动域。

## O6-01 — 让传播场随水深、潮位和域移动生效

- [ ] **产出：** 地理定位稳定的传播/暴露场、明确失效与回退规则及最小数值证据。
- [ ] 从 O5 取得有效水深、海洋连通性、覆盖/分辨率和坡度；无效数据不参与精确传播。
- [ ] 将 Tidewater arrival/exposure 思路移植到当地切平面，并保留地理定位与球面重定位协议。
- [ ] 分离固定地形/拓扑输入和当前潮位输入；潮位变化影响水深与传播速度，不能无限复用旧预烘场。
- [ ] 选择可说明的分档预烘、受预算约束的重算或其他近似，记录误差和更新条件，避免每帧全域重建。
- [ ] 处理数据块边界、岛屿/岬角遮挡、相机跨域、原点重置和风浪方向改变；过期结果不得回写。
- [ ] 更新尚未完成时保留仍有效结果或平滑减弱近岸效果；不把随机方向补丁当作传播求解。
- [ ] **检查：** 缓坡与海湾夹具的波向/暴露变化合理；孤立内陆洼地无传播，缺数据路径可解释。
- [ ] **退出：** 当前传播场可追溯到对应数据、潮位范围与域版本，变化不产生无界计算或陈旧岸浪。

## O6-02 — 衔接远海 FFT、浅化与代表岸型碎浪

- [ ] **产出：** 连续的离岸到近岸波面，以及代表岸型的可复现视觉证据。
- [ ] 先完成有可靠数据的缓坡沙滩，再验证海湾/岬角或小岛、陡岸等至少一种非缓坡岸型。
- [ ] 按当地水深、坡度和暴露控制波幅、波长/波向近似及碎浪区；不全局套用固定沙滩坡度。
- [ ] 在过渡区域协调 FFT 位移与近岸波位移，避免双重叠加能量、法线跳变及两套相位相撞。
- [ ] 用同一水面查询约定支撑可见曲面和后续水线；明确解析近似与几何实际位移的关系。
- [ ] 陡岸、低分辨率海岸或未知底形采用受限效果；标注能力边界，不能把沙滩卷浪强贴到所有岸型。
- [ ] 保持太阳/天空/云近似反射、水深海色和地形遮挡在浅水中连续；SSR 不作为完成条件。
- [ ] **检查：** 固定相机、岸向移动、掠海视角和潮位两端无明显网格裂缝、岸浪方向突变或穿陆。
- [ ] **退出：** 代表岸型通过对应效果验收，其余范围有明确可工作的数据/质量回退。

## O6-03 — 泡沫、湿沙及潮间带历史

- [ ] **产出：** 空间稳定、有界且可重建的岸边泡沫/湿润历史和涨退潮演示。
- [ ] 将白沫产生、衰减、残留和湿沙响应拆清；泡沫与湿沙不能共用一个含义不明的亮度贴图。
- [ ] 历史以地理位置或可追踪移动域定位，不能因相机中心改变而把整片泡沫/湿沙拖走。
- [ ] 小移动按已验证的重投影/滚动方式保留有效历史；大跳转、跨域和原点失效按 O4 有界重建。
- [ ] 当前水位叠加近岸浪涌只在海洋连通候选域内改变干湿；退潮后湿沙留存按 Cesium 时间演化。
- [ ] 湿沙改变地形表观时限定海岸范围和数据有效区，保留实际地形深度，不能把整片低地涂成湿沙。
- [ ] 暂停时停止累积/衰减，倒播和跳时重建遵守 O4；不得使用负 dt、巨大 dt 或墙钟淡入。
- [ ] **检查：** 同一地理位置在镜头绕行后历史仍对齐；涨潮/退潮、暂停、倒播、瞬移及缺块无爆亮拖影。
- [ ] **退出：** 潮间带可见移动且不会侵入不连通洼地，历史成本有界，允许的重建渐入已记录。

## O6-04 — 海岸效果与正式性能验收

- [ ] **产出：** 同源版本的代表岸型效果、稳定性、质量等级与正式性能报告。
- [ ] 沿用 O3 的硬件、分辨率、画质和记录约定；新增近岸数据/传播/历史成本，不自造帧率目标。
- [ ] 分别测量海洋关闭、开阔海、近岸开启的可比较场景，记录平均/p95 帧时间、可用 GPU 阶段耗时、分配字节/资源计数和加载峰值。
- [ ] 性能目标和降级规则采用已批准验收预算；若测量显示预算不可达，记录瓶颈与具体取舍请求。
- [ ] 验证局部域移动、潮位更新、缺数据、加载失败、海洋开关和销毁；避免每帧 CPU 回读 GPU。
- [ ] 正式视觉矩阵仅在本阶段关联修改稳定后执行，含代表岸型、主要潮位和时间/相机操作。
- [ ] 聚焦数值/状态测试合并执行；实际共享渲染变化补必要 WebGL smoke，复用仍适用的 M5/O3 证据。
- [ ] **检查：** 记录实际物理 GPU、测试 revision/bundle、数据精度、暖机/采样方法、质量档和结果。
- [ ] **退出：** O6 效果与性能门通过或明确 blocked/unverified，已知限制可复现且没有被降级隐去。

## 最小充分验收

| 风险 | 必要证据 |
| --- | --- |
| 静态预烘不适配潮位 | 传播场输入版本、更新条件及不同潮位对比 |
| 固定坡度误用 | 缓坡及非缓坡岸型对比，精度/回退说明 |
| 相机移动破坏历史 | 沿岸移动、跨域、瞬移和时间重置序列 |
| 成本失控 | O3 可比条件下近岸增量与峰值测量 |
| 近岸侵入内陆 | 海洋连通、潮间带和孤立洼地的检查结果 |

遵守 [CI](../../docs/CI.md)：禁止 SwiftShader；物理 GPU 不可用记 blocked/unverified。
分配字节不能声称为驱动实际 resident VRAM；缺少 timestamp-query 时说明 GPU 计时限制。
O6 是明确的局部硬件验收节点，不等于授权手工 Full 或重复全套回归；Full 仍需相应授权。
验收报告按代表岸型与数据状态分别给结果，不能以单个理想沙滩覆盖全球通过。

## 风险与回退

- 岸浪参考依赖局部近似：先证明代表岸型；全球体验按数据精度分级，不承诺处处真实。
- 潮位持续变化使传播缓存失效：采用有依据的更新阈值/分档与平滑策略，记录剩余误差。
- 历史域扩大会使显存或带宽失控：按预算限制域和质量，保留可视化诊断及重建语义。
- M5/开阔海既有成本可能挤占预算：分项报告，不通过关闭既有有效门或删除断言掩盖。
