# M0 — Official baseline + minimal WebGPU backend

**Status:** Not started (upstream source import completed).
**Goal:** establish repeatable original WebGL behavior plus minimally functioning WebGPU drawing. Do not implement full renderer abstraction, Atmosphere, Terrain or 3D Tiles here.

## Incremental tasks
1. **M0.1 Verify pinned source.** Confirm the root version `1.146.0`, upstream SHA in `coordination/UPSTREAM_REVISION.txt`, current package tree and Apache license. Record SHA and source audit.
2. **M0.2 WebGL baseline.** Follow upstream Node/npm workspace instructions in `package.json`, install dependencies, run official build/test/smoke demo and record command versions + outcomes. No source edits until baseline documented.
3. **M0.3 Source exploration.** Trace Viewer -> Scene -> Globe -> terrain/imagery tile commands -> WebGL renderer. Document actual symbols/paths and CPU vs GPU responsibilities. Read-only parallel subagent allowed.
4. **M0.4 WebGPU proof.** Introduce backend selection at Viewer creation (WebGL remains default); configure canvas/device; render clear, triangle and depth; verify resize/error handling. One integration owner owns shared Scene/Viewer files.
5. **M0.5 Regression gate.** Verify existing WebGL still works and a WebGPU example initializes without validation errors. Record results and remaining blockers.

## Acceptance
- Official WebGL demonstration runs with no regression.
- Separate WebGPU Viewer initialization and basic GPU pass operate.
- No claimed Globe/terrain support until M1.
- Build/test commands, logs and diagnostics in a short handoff.

## Safe parallelism
Independent source audit, test harness exploration and WGSL experiment (isolated files) may run concurrently. **Shared Viewer/Scene initialization is serialized.**
