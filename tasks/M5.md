# M5 — V1.0 visual quality, stability, release gate

**Prerequisite:** M0–M4 verified.

## Tasks
1. Produce repeatable reference views: orbital daytime, sunrise, twilight, night, low-altitude cloud sea, inside cloud, terrain shadows, rapid camera motion.
2. Compare camera altitude/time continuity in sky, cloud, aerial perspective and terrain lighting; eliminate noticeable abrupt transitions.
3. Fix temporal shimmer, ghosting, density popping and resource lifetime bugs; verify resize and device loss recovery.
4. Profile GPU pass time and memory separately for globe, atmosphere, cloud and shadow; log test hardware/browser/resolution. **Do not claim a universal 30 FPS target without a specified baseline GPU.**
5. Run upstream WebGL build/tests and targeted regression; record unsupported WebGPU APIs clearly.
6. Complete A01–A18. Deliver concise limitations and fixed sample scenes.

## V1.0 definition
High-quality Globe, imagery, Terrain, atmosphere, Sun, sky/stars/Moon, HDR, spherical clouds and terrain cloud shadows. **3D Tiles is not a blocker for V1.0.**

## Parallelism
QA scenes, profiling/reporting, and code review can run concurrently. Shared renderer fixes are serialized and reviewed.
