# M5 — V1.0 visual quality, stability, release gate

**Prerequisite:** M0–M4 verified.

## Tasks

1. Produce repeatable reference views: orbital daytime, sunrise, twilight, night, low-altitude cloud sea, inside cloud, terrain shadows, rapid camera motion.
2. Compare camera altitude/time continuity in sky, cloud, aerial perspective and terrain lighting; eliminate noticeable abrupt transitions.
3. Fix temporal shimmer, ghosting, density popping and resource lifetime bugs; verify resize and device loss recovery.
4. Profile GPU pass time and memory separately for globe, atmosphere, cloud and shadow; log test hardware/browser/resolution. **Do not claim a universal 30 FPS target without a specified baseline GPU.**
5. Run upstream WebGL build/tests and targeted regression; record unsupported WebGPU APIs clearly.
6. Complete A01–A18. Deliver concise limitations and fixed sample scenes.

## V1.0 definition

High-quality Globe, imagery, Terrain, atmosphere, Sun, sky/stars/Moon, HDR, spherical clouds and terrain cloud shadows. **3D Tiles is not a blocker for V1.0.**

## Reference scenes

Task 1 is complete on the local M5 branch. The [eight reference captures and physical GPU report](../coordination/evidence/M5/reference-scenes/README.md) record the example revision, reset checks and camera replay.

Serve the built checkout with `npm run demo:webgpu` and open the [reference scene example](http://localhost:8067/Apps/WebGPUReferenceScenes.html). The fragment selects the starting scene. Reset restores the prescribed camera and clock. The rapid-motion scene also supports single-frame stepping and replay.

| Scene | Reference use |
| --- | --- |
| [Orbital daytime](http://localhost:8067/Apps/WebGPUReferenceScenes.html#orbit-day) | Daylit globe and atmosphere at orbital distance |
| [Sunrise](http://localhost:8067/Apps/WebGPUReferenceScenes.html#sunrise) | Low eastern Sun and morning illumination |
| [Twilight](http://localhost:8067/Apps/WebGPUReferenceScenes.html#twilight) | Western horizon with the Sun below the local horizon |

The [M4 acceptance packet](../coordination/evidence/M4/final-acceptance/README.md) remains the source for accepted A14/A15 behavior and the measured altitude fade. The terrain-shadow reference uses the accepted Golden Gate camera, time and lighting settings. Its terrain and satellite tiles come from live Esri services, so archive the capture when comparing revisions. A16 stress acceptance, A17 duration testing, profiling and A18 final regression are separate tasks.
