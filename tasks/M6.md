# M6 — V1.1+ 3D Tiles, photogrammetry and BIM (deferred)

**DO NOT START before the V1.0 Globe is validated unless project owner explicitly reprioritizes.**

## Tasks
1. Define sample compatibility matrix for common 3D Tiles 1.0/1.1 mesh content; include relevant batched/GLB content and necessary Draco/KTX2.
2. Trace upstream tileset LOD, resource cache, model pipeline and metadata behavior, and reuse loading/scheduling where practical.
3. Render common mesh geometry, textures and basic PBR with georeferenced transforms.
4. Integrate sunlight/moonlight, atmosphere aerial perspective and cloud-shadow reception into supported mesh materials.
5. Validate city buildings, inclined photogrammetry and BIM data in representative scenes; keep regression cases.

## Non-goals
Point clouds, the entirety of 3D Tiles 1.1 extensions, full metadata styling/picking, classification/clipping and advanced GI/shadow systems.
