# M3 — V0.3 global spherical volumetric clouds

**Prerequisite:** Sun and atmosphere working from M2.

## Tasks
1. Define a curved cloud layer tied to Earth radius and geographic location; verify ray entry/exit in orbit, high altitude and near ground.
2. Generate procedural global coverage, wind advection and spatially varying density/3D noise.
3. Build volumetric integration with transmittance, anisotropic scattering, cloud self-shadow and sunlight edge/silver lining.
4. Support orbital LOD to closeup and in-cloud traversals without switching to an unrelated planar cloud system.
5. Improve temporal behavior (reprojection/history only if evidence shows it is required); test pan/zoom/fast flight and day-night progression.
6. Capture A11–A13 with correct cloud silhouette, thickness, lighting and stable motion.

## Non-goals
Terrain cloud shadows (M4), realistic meteorological API, rain and snow.

## Parallelism
Noise generation, scene fixtures and physics reference analysis can be separate. **Final cloud pass, depth compositing and temporal resource integration require single ownership.**
