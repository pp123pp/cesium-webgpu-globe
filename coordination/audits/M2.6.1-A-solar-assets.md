## Conversion and upload

- coordination/ci/build-solar-textures.mjs reads each SVG, creates a data URL, decodes it in Playwright Chromium, draws to a 512×512 Canvas and reads pixels. Mask assets retain the alpha byte in R8; the gradient retains all RGBA bytes.
- packages/engine/Source/Scene/WebGPUAtmosphereRenderer.js fetches the eight .r8/.rgba8 payloads through buildModuleUrl, validates exact byte length, creates r8unorm or rgba8unorm-srgb sampled textures and queue.writeTexture uploads them once during asynchronous initialization.
- Runtime sampler uses linear min/mag and clamp-to-edge. No mipmaps or mip generation are present.
- If an optional payload fails, already-created solar textures are released and one-pixel neutral fallback textures are installed. Device loss is not treated as an optional-asset failure. Existing M2.6 fallback smoke covers 404/corrupt payload cleanup.

## Risks and recommendations

1. 512² is the current authored base resolution, but the shader samples LOD 0 and no mipmaps exist. Test 1920×1080, 1280×720 and small/off-axis apparent Sun cases before deciding whether mip generation or resolution changes are justified.
2. Three ray maps share one UV transform. Consider controlled independent angular rotation/scale/offset or deterministic phase variation in B only if matched captures prove repetition.
3. One fine corona mask plus one modulation map is not a true multi-band corona asset set. Add a second authored frequency band only if B visual comparisons demonstrate missing structure.
4. No PNG/WebP is required by current runtime. R8/RGBA8 raw payloads are already GPU-ready and avoid runtime SVG decode. Do not replace them without evidence of a concrete authoring, bandwidth or quality advantage.
5. Manifest and README identify all artwork as original repository-authored SVGs with no third-party dependencies. Preserve that provenance and license record when modifying artwork.
