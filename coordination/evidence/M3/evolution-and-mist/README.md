生长与飞行以 3 秒模拟时间为采样间隔，从 0 到 60 秒各 21 帧。每采样帧播放 180 ms，主体约 16.7 倍速；最后一帧额外停留。晨间横移和关闭云隙动画采用不同时空状态的采样展示，太阳时刻固定。这些片段不能测量连续一分钟内每个显示帧的抖动或游戏帧率。

- 云生长从 0°、0°、6.9 km、航向 247°、俯角 8° 开始。UTC 2026-03-20 16:30，覆盖率 0.58、风速 18 m/s、方向 0.75 rad。飞行镜头向东移动约 5.57 km，同时从 6.9 km 降到 5.74 km。
- 晨间对照保持 UTC 07:10、600 m、航向 20°、仰角 7°、无风。横移覆盖率为 0.58。闭合云隙对照取 11 个覆盖率值，从 0.15 到 1.00。原图中 x=181..238、y=221..239 的区域（左上角为原点），候选相对基线的平均亮度增量从 +4.76 降至 −0.88 个 8 位色阶。该局部已经混合雾的散射与衰减，不代表整幅图全部光束都消失。效果较弱，可查看[晨间原图](mist-midpoint.png)。
- 候选关闭新效果后，固定视角及晨间视角分别与对应基线 PNG 按字节一致。开启晨雾并将覆盖率设为零，与完全关闭云的原帧也按字节一致。
- 针对 180 秒周期边界，在移动相机下额外采集了 13 个 1/30 秒间隔的相邻帧。GPU 相位跨回到 1 时，相邻帧的全图平均最大通道差为 0.0582 个 8 位色阶，邻近帧为 0.0368–0.0601。本检查只覆盖该机位的 0.4 秒。[跨周期实测](phase-wrap-result.json)
- 两侧都通过物理 GPU 截图，零浏览器错误或警告。追踪与重建的十帧合计均值 / p95，从基线到候选，飞行终点为 10.28 / 14.29 → 7.79 / 9.04 ms，横移终点为 9.69 / 13.24 → 8.85 / 10.29 ms。采样时间不同，这组数据只描述该设备的两次短采样。
