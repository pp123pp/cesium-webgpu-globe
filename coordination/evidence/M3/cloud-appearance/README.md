# M3 近景云层外观对照

**2026-11-05 用户确认云层渲染效果视觉验收通过，并授权推送及合并到 main。** 验收覆盖近景云冠、云体内部明暗以及飞行横纹。远轨道无体积云已作为 A11 需求更改单独确认。左列为修改前，右列为本次验收版本。两侧使用同一物理 Intel Xe-LPG、Chrome 156.0.8078.80、生产 WebGPU 渲染路径和离线有界地形。每对相机、时刻、曝光、覆盖率、风、质量档和画布尺寸一致。

- [云冠对照](cloud-crowns.png) 展示地面视角中央的斜切边、右侧尖角，以及俯视云海。两行均为原生 1:1 裁切。左上原尖峰在右上变得更圆，前景云体仍偏软。
- [日落与云内对照](cloud-lighting.png) 展示完整原帧。日落画面的云隙和背光区域出现更深的明暗分隔，云内视角的前景仍然偏白。
- [飞行横纹对照](flight-striations.png) 展示两帧全图和同位局部。局部采用 4 倍最近邻放大，每个原像素复制为 4×4 像素。两侧使用相同裁切坐标，保留原始颜色。

## 飞行横纹

在所示原图的相同像素区域，用 8 位 RGB 的 `0.2126 R + 0.7152 G + 0.0722 B` 计算每行平均亮度。将行均值减去上下两行均值的平均，得到残差；去除首尾两行，再取奇偶交替加权的残差均值的绝对值。较小的数字表示该固定区域按扫描行交替出现的亮度起伏减弱。

| 帧 | 含端点的原图像素范围 | 修改前 | 最终候选 |
| --- | --- | ---: | ---: |
| 飞行 07 | x 2–65，y 133–165 | 0.29490 | 0.00588 |
| 飞行 18 | x 274–310，y 150–181 | 0.39461 | 0.04140 |

两个局部的密集横纹明显减弱。飞行 18 的较宽水平结构仍可见。这项测量只描述两张定点截图，长时间运动稳定性仍待单独评估。
