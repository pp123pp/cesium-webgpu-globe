# M3 云性能实验

运行时代码提交为 `f746d27`，起点为 `67bd106`。在云可见距离内，零覆盖现在跳过云对象的创建、参数上传和绘制，仍会校验云选项。已有资源留待恢复覆盖率时复用。两个有云着色器实验均已撤回。

## 物理 GPU 与画面验证

Intel Xe-LPG，Chrome 156.0.8078.80，离线有界椭球地形。三个 720p/Medium 机位均追踪 640×360。每个机位先预热 20 帧，再记录 120 组 WebGPU 时间戳，分别计追踪和重建。逐帧配对相加后计算云合计均值与 p95。每帧等待读回，结果只代表云 GPU pass。下表单位为 ms。

| 着色器实验顺序 | 层积云均值 | 云隙加卷云均值 | 水平云海均值 |
| --- | ---: | ---: | ---: |
| B1 零覆盖修复 | 12.57 | 11.51 | 10.83 |
| T 跳过零贡献纹理 | 10.99 | 11.57 | 11.21 |
| B2 同一基线 | 10.06 | 11.17 | 12.23 |
| G 跳过确定空高度带 | 11.93 | 11.20 | 11.04 |
| B3 同一基线 | 10.66 | 10.37 | 12.18 |

T 在层积云的耗时落在两次基线之间。G 在目标卷云机位慢于两次基线。G 在水平云海的下降发生在关闭卷云的对照机位，无法归功于空带跳步。两项均未达到目标场景收益超过基线波动的门槛。接受的原始构建 A1、B1、T、B2、G、B3 和提交后重建均得到相同的八张 PNG 哈希，包含积云、层积云、薄卷云、暮光与水平云海。

| 提交后重建 | 追踪均值 | 重建均值 | 云合计均值 | 云合计 p95 |
| --- | ---: | ---: | ---: | ---: |
| 层积云 | 10.24 | 0.47 | 10.71 | 12.52 |
| 云隙加卷云 | 9.95 | 1.05 | 11.00 | 12.71 |
| 水平云海 | 10.22 | 0.57 | 10.79 | 13.04 |

零覆盖回归夹具在 A1 的第一项 pass 断言失败，观测为 1、期望为 0。修复后，零覆盖首次启用时未分配云对象，追踪与重建均为 0。首次恢复覆盖率后各提交 1 个 pass，再次清空、再恢复时分别复现对应原图。用 8 km 高的真实地形网格遮挡低云时，启用云与关闭云的图像哈希相同。提交后构建重复通过这些检查。

## 追踪成本归因

在诊断浏览器中，只拦截标记为 `M3 volume integration` 的着色器模块。向光诊断保留 `localExtinction * 75.0`，略去沿太阳方向的额外密度采样；空气透视诊断仅将云辐射函数的一次 `atmosphereIntegrate(ray, distance)` 替换为零辐射、单位透射。晨雾对照使用生产开关，保持晨间机位、太阳、风和覆盖率相同。下列每组三段使用同一构建 `79211c4c`；每个数值为追踪与重建的合计均值。

| 顺序 | 层积云 | 晨间关雾 | 晨间开雾 |
| --- | ---: | ---: | ---: |
| D4 原始 | 11.44 | 17.56 | 21.11 |
| L2 略去向光子采样 | 7.08 | 8.76 | 13.34 |
| D5 原始 | 10.67 | 16.72 | 21.17 |
| D2 原始 | 12.09 | 16.48 | 19.59 |
| P 略去云空气透视积分 | 9.73 | 15.06 | 25.75 |
| D3 原始 | 11.84 | 16.79 | 23.93 |

**下一项优先验证向光密度采样。** 略去这部分后，三个场景的耗时均低于前后基线，幅度也超过基线波动。下一次可单独比较光线上无贡献的噪声细节和相邻主样点间的太阳透射复用，用已签收的云内明暗、银边及飞行序列验收。空气透视在层积云机位有明确成本，晨雾机位的结果则随场景而变。D4、D5 中，开启晨雾的均值分别增加 3.55、4.45 ms。两种着色器诊断均改变输出，仅用于选择下次实验，不作为可交付提速。较早的 D1、L、D2 跨越两份 bundle，原始数据保留，向光结论使用 D4、L2、D5。

## 首次开云

提交后构建上，一次冷启动测得零覆盖的 `viewer.render()` 同步返回 0.7 ms；首次可见云为 18.9 ms，从调用到整帧 GPU 队列完成共 891 ms。随后八帧同步返回为 0.6–0.9 ms。独立导入生产噪声函数，首次调用为 16.6 ms，后五次为 13.6–14.2 ms，六次生成纹理的内容完全相同。冷启动只采了一次；891 ms 包含整帧提交、队列等待及浏览器调度，不能归为噪声生成或某个云 pass 的独立耗时。
