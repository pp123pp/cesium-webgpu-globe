# 金门地形云影与影像重复绘制

2026-11-06，本地 Intel Xe-LPG、Chromium 156.0.8078.4、1280×720。金门机位固定在西经 122.489°、北纬 37.8113°、海拔 1900 m，朝向 313°，俯角 28°，UTC 2026-03-20 20:00。归档了 Esri 的 137 个高程响应和 728 个影像响应；后续测量从本机按内容哈希回放。各轮校验相同相机、时钟和瓦片清单，完整画面每帧有 13 次地形绘制和 221 次影像绘制。地形和卫星影像分别来自 Esri World Elevation 3D 与 World Imagery。[带来源标注的参考场景](../reference-scenes/README.md)

## 选择优化项

下表是同一基线的两轮诊断，第二轮交换了关云影与减少影像的测试次序。完成帧率取 GPU 队列完成回调的样本数除以总间隔；rAF 为浏览器前台渲染回调。去除某项后的帧率是成本上限，因为这些诊断会改变画面。

| 诊断 | 完成帧率，第一轮 / 第二轮 | rAF 间隔 p95，ms | 影像绘制/帧 |
| --- | ---: | ---: | ---: |
| 完整基线，区块起始 | 27.91 / 30.40 | 50.1 / 66.7 | 221 |
| 仅关闭地形云影 | 45.13 / 46.12 | 33.4 / 33.5 | 221 |
| 保留每块地形的首张就绪影像 | 43.89 / 41.91 | 33.4 / 33.5 | 13 |
| 完全跳过影像绘制 | 46.53 / 未重复 | 33.4 / — | 0 |
| 恢复完整基线 | 30.13 / 31.41 | 50.2 / 50.1 | 221 |

两项成本接近。两轮中关云影的完成帧率均略高，rAF p95 持平；完成回调 p95 的相对排序随轮次改变。因此先验证云影能否在保留画面时兑现收益。影像重复绘制留待独立实验。

## 保留的实现

每帧先在半宽、全高的 `rg16float` 纹理上计算偶数列地形接收点的太阳直射和环境光透射。奇数列仅在两侧都受光、地形深度相容时插值。阴影梯度陡峭时按通道独立回到原积分，保证环境光开关不会改变直射结果。天空或地形边缘、缺少右邻的最后一列也使用原积分。太阳圆盘的三条射线和实时风场仍参与计算。720p 附加纹理占 1,843,200 字节，关闭云影时释放。

以源码基线 `43e6e6f` 和当时工作区中的云噪声、向光采样改动为共同起点。旧版 A 和修正版 B 的完整 bundle 哈希保存在汇总文件中。固定瓦片上按 A/B/A/B/A 运行，每块预热 20 帧，记录 120 个连续渲染间隔。另行预热 10 帧、记录 60 帧的 GPU pass 时间戳与逐帧等待队列完成的墙钟时间。指标从原始样本合并计算。

| 指标 | A | B |
| --- | ---: | ---: |
| GPU 队列完成帧/秒 | 28.42 | **33.43** |
| rAF 帧/秒 | 28.42 | 33.10 |
| rAF 间隔 p95 | 66.7 ms | 50.5 ms |
| GPU 完成回调间隔 p95 | 68.4 ms | 65.4 ms |
| 单帧渲染至队列完成 p95 | 45.3 ms | 40.4 ms |
| 整帧 GPU 首末 pass 时间戳跨度，均值 | 34.10 ms | 29.85 ms |
| 云影预计算 + 大气合成，均值 | 18.70 ms | 4.46 + 10.66 = 15.12 ms |

两个候选区块的完成帧率为 33.16、33.70，三个基线区块为 29.97、29.47、26.13。机器负载有波动，个别区块的尾部间隔会反向变化。结论限于这个固定机位、适配器和分辨率，屏幕呈现帧率未单独测量。[分区块与合并统计](measurements.json) · [原始样本和有界验收记录](samples.json.gz)

## 画面与验收

修正版两次捕获的完整图像一致，关闭云影的对照与基线逐像素一致。开启云影后，921,600 个像素中有 33,669 个像素发生变化，全帧 RGB 平均绝对差为 0.01271 个 8 位码值，最大单通道差为 1。在基线开关云影的亮度差至少为 3 的 433,237 个像素上，阴影信号归一化平均误差为 0.213%，相关性为 0.999785。[画面对照与放大差图](comparison.png) · [逐像素统计](image-metrics.json)

首个候选因两通道共用回退判定，打开环境云影后有 5 个像素变亮，已淘汰。修正版通过 M4 地形与椭球物理 GPU 夹具，覆盖直射/环境开关、真空与大气、瓦片边界、低太阳角半影、动态风、云层上方和夜间。另验证 321×181 奇数尺寸下缓存为 116,564 字节，关闭后为零。

## 复测

构建并服务检出的版本。用 `M1_BASE_URL` 指向实际服务，`M5_GOLDEN_ROOT` 指向各版本共用的归档，`M1_OUTPUT` 为每次运行指定单独目录。使用仓库现有的物理 GPU 配置。

1. 在基线上运行 `node coordination/ci/m5-golden-gate-profile.mjs --record --diagnose`，采集响应和瓦片清单。
2. 在同一基线上使用 `--reverse` 回放归档并交换诊断次序。
3. 分别在 A 和 B 的构建目录运行 `node coordination/ci/m5-golden-gate-profile.mjs`，交错重复。默认模式记录完整帧计时、完整图像及关云影对照。实时 Esri 服务日后可能返回不同数据；本轮原始选中瓦片、相机、bundle 与图像哈希均已归档。
