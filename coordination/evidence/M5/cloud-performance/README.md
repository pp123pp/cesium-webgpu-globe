# 体积云向光采样复用与静态噪声

2026-11-06，在本机 Intel Xe-LPG、Chromium 156.0.8078.4、1280×720、Medium、640×360 云追踪分辨率下比较。两版均以 `18e4c8a` 工作树为基础，包含同一份并行开发中的大气与晨昏云环境光修正。A 使用原始向光积分与运行时噪声生成。D 仅将相邻受光主样点配对，并将完全相同的噪声字节内嵌到 bundle。每个样点仍单独计算 75 m 近场消光；如果前一步为空或未受光，当前步重新计算远场光深。关闭云和运行时调风、卷云、天气演变保留原语义。

## 稳态帧

显示器空闲 rAF 约 60 Hz。固定相机、UTC、风场和有界地形，两个页面仅在前台采样时逐帧渲染。逐机位分别跑 A/D/D/A 和 D/A/A/D，每个区块预热 20 帧再记录 120 个间隔，共 480 个间隔/版本/机位。完成速率取帧数除以 GPU 队列完成回调的总间隔；rAF 间隔用于交叉检查浏览器调度。两者均不测屏幕实际呈现。另行测量 GPU pass 时间戳和从 render 开始至队列完成的墙钟时间，后者逐帧等待。表内为 A → D。

| 机位 | 队列完成帧/秒 | rAF 帧/秒 | rAF 间隔 p95，ms | GPU 云追踪均值，ms | 单帧至队列完成 p95，ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 层积云 | 28.63 → 34.67 | 28.63 → 34.57 | 66.6 → 50.1 | 16.27 → 10.47 | 96.7 → 46.4 |
| 云隙与卷云 | 40.64 → 41.51 | 41.08 → 41.74 | 50.0 → 50.0 | 11.84 → 10.49 | 37.7 → 31.6 |
| 水平云海 | 33.52 → 32.82 | 33.92 → 32.62 | 50.1 → 66.6 | 10.73 → 9.69 | 60.1 → 44.8 |

层积云收益最清楚。水平云海第一组偏向 A，反序组偏向 D，合并后帧率略降，rAF p95 增加一个刷新间隔。这组数据不能支持水平云海帧率改善。保留 D 的依据是层积云帧率和尾部时间改善、三个机位的追踪成本都降低。最初尝试的 75 m 内复用覆盖面有限；无奇偶对齐的连续复用在初筛中出现明显整帧回退，两者均未采用。

## 首次开云与资源成本

| 指标 | A | D |
| --- | ---: | ---: |
| 新页面首次开云同步 CPU，中位数 | 21.9 ms | 3.8 ms |
| 新页面首次开云至队列完成，中位数 | 1269.8 ms | 1196.6 ms |
| 同页重建 Viewer 后首次开云同步 CPU，中位数 | 17.2 ms | 2.3 ms |
| 同页重建 Viewer 后首次开云至队列完成，中位数 | 78.7 ms | 49.0 ms |
| 独立噪声准备至纹理上传完成，冷 HTTP 缓存中位数 | 21.3 ms | 2.9 ms |
| gzip bundle 大小 | 2,922,013 B | 3,053,782 B |

首次开云每版启动三次独立浏览器，每次验证实际提交云追踪和重建 pass、复开后的画面区别于关云。驱动缓存未清除。整帧包含首次管线创建及浏览器调度，无法将其全部差值归给噪声。另用五轮交替顺序测回环 HTTP gzip 动态脚本加载并执行，冷缓存中位数 408.8 → 413.6 ms，暖缓存 399.2 → 414.5 ms。冷缓存每次实际发出一个请求，暖缓存零请求。云关闭时 bundle 也携带该资源，仅在建云时解码；两版 GPU 噪声纹理均为 131,072 字节。

## 画面

8 个静态视图、78 张运动或控制图均在相同时间、视角与配置下比较。静态差异最大的是层积云，平均绝对 RGB 差为 0.221 个 8 位码值。所有图像的单通道最大差为 6。70 个相邻帧区间中，最大平均时序残差为 0.201 个码值，出现在飞行序列。变化集中在云受光面；关云和零覆盖两组逐像素一致。这些结果覆盖本次机位，人工视觉签收仍由使用者决定。

## 复测

- 使用 `node coordination/ci/build-cloud-noise.mjs --check` 检查离线生成结果，运行 `node --test coordination/ci/m3-cloud-noise.test.mjs` 核对验收噪声的 SHA-256、对比度和周期边界。
- 构建并分别服务 A 与 D。使用仓库硬件浏览器配置，按版本设置 `M1_BASE_URL` 和独立的 `M1_OUTPUT`。从对应 bundle 所在的工作目录运行 `node coordination/ci/m3-volume-smoke.mjs`，分别附加 `--cloud-types --profile --cadence`、`--first-cloud`、`--motion-and-mist`、`--clear-coverage`，各模式保存至独立输出目录。
- 标准夹具的单版本运行可复测画面、pass 与帧间隔。表中配对实验在同一个 Chromium 会话中分别加载两个已核验的 bundle，以相反顺序重复上述三个固定机位。原始记录保留每个顺序、区块与间隔，可独立重算。
