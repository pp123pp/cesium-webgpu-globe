# 金门影像重复绘制

2026-11-06，使用本地 Intel Xe-LPG、Chromium 156.0.8078.4、1280×720。A 是上一轮已验收的云影 bundle（`b43861ed…`），B 是加入高度图影像索引优化后的 bundle（`364d7144…`）。复用上轮归档的 Esri 高程与卫星影像响应、相机、UTC 和选中瓦片清单（`7b506dd7…`）。全效果基线截图也与上轮最终候选逐字节一致。[云影基线与机位](../golden-gate-performance/README.md)

## 减少提交的几何

13 块可见地形各有 1 张底图和 16 张卫星影像。两版每帧均绘制全部 221 个影像关联。B 只对稠密的原生规则高度图启用紧凑索引。每种拓扑在第一次匹配时生成一份共用 GPU 缓冲，包含 4×4 个略有重叠的地形区域。只有影像的整个裁剪矩形落在一个区域内才选择其索引范围。使用真实解码的地理 V 或 Mercator T 判断范围，并保留原三角形顺序、裙边及片元裁剪。跨区影像、地形填补、定制建网和逐片元计算 Mercator T 的路径使用原索引。

完整帧中，208 个卫星影像绘制命中紧凑索引，地形和 13 个底图绘制继续提交全块。实测每帧影像索引由 **88,258,560 降至 11,823,864（−86.6%）**；地形本身仍为 5,191,680 个索引。新增一个共享 GPU 缓冲，占 2,040,672 字节。两次冻结输入的加载记录中，网格准备累计为 2.1、2.8 ms，包含首次建缓冲的同步渲染帧分别为 12.2、11.9 ms。销毁 Viewer 后索引缓存数量和字节数均归零。

## 整帧与 p95

按 A/B/A/B/A、B/A/B 顺序运行。每块从预热后的 120 个连续前台渲染间隔计算吞吐，另用 60 帧逐帧等待队列完成并采 GPU 时间戳。每版共有 480 个连续渲染间隔及 240 个独立的串行样本。FPS 以完成数除以区块总时间，p95 从原始间隔合并计算，保留所有区块。GPU 完成回调和 rAF 描述浏览器渲染节奏，未单独测量屏幕呈现。

| 指标 | 云影基线 A | 影像优化 B |
| --- | ---: | ---: |
| GPU 完成帧/秒 | 29.14 | **39.27** |
| rAF 帧/秒 | 28.71 | 39.29 |
| rAF 帧间隔 p95 | 66.6 ms | 50.0 ms |
| GPU 完成回调间隔 p95 | 65.4 ms | 50.6 ms |
| 地形与影像 pass 均值 / p95 | 12.94 / 17.17 ms | 4.99 / 6.16 ms |
| 整帧 GPU 首末 pass 跨度均值 / p95 | 29.93 / 39.12 ms | 26.49 / 41.68 ms |
| 单帧提交至队列完成均值 / p95 | 33.73 / 43.1 ms | 30.36 / 45.3 ms |

候选的四个区块分别达到 41.60、35.53、42.04、38.65 完成帧/秒，基线范围为 26.68–31.31。保留优化的依据是四块的完成帧率都高于基线，连续渲染的尾部间隔也缩短。串行整帧的均值降低，但 GPU 跨度 p95 和等待队列完成 p95 都升高；部分候选区块的大气与云影耗时偏高。结果仅覆盖该机位和本机物理 GPU。[各区块与汇总](measurements.json) · [原始样本及绘制诊断](samples.json.gz)

## 画面与检查

完整画面、关闭云影、卫星层 alpha = 0.5 且关闭裙边三组对照，每组 **921,600 个像素 RGBA 全部相同**。首轮五个区块保存了三种对照；后续反序复测保存了完整画面与关云影对照。原始截图按相同相机、时间和纹理清单比对。[画面对照](comparison.png) · [逐像素指标与 PNG 哈希](image-metrics.json)

- 构建、ESLint、55 项定向 CPU 测试通过。新增的高纬非方形原生高度图用例直接核对每个被省掉的三角形都落在影像覆盖区外，保留三角顺序和完整裙边，并区分地理 V 与 Mercator T。
- 现有 M1 影像浏览器夹具在 A、B 上均停止于相同的地理坐标颜色断言。两版的 204 个颜色检查均失败，最大差值同为 28.51745，断言文本相同；此前三张 Natural Earth 截图哈希一致。夹具随后定义的 Mercator 与图层检查未执行。本轮未运行全量回归。
- 复测时分别构建 A 与 B，设置 `M1_BASE_URL` 为对应服务、`M5_GOLDEN_ROOT` 为上一轮的冻结归档，`M1_OUTPUT` 为各区块指定独立目录。运行 `node coordination/ci/m5-golden-gate-profile.mjs --imagery-load` 记录绘制索引、加载开销、半透明对照及销毁计数；省略该参数可单独复测完整帧计时。保留归档，避免实时 Esri 瓦片更新影响比较。
