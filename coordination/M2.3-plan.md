## Interface decisions

`scene.sun` is WebGPU-only settings: `show`, `angularRadius` (0.00465 rad), `displayScale` (pi*sin(0.00465)^2/10 sr), `glowStrength` (0.025), `glowRadius` (0.025 rad). Native Viewer `skyBox:false` also initially hides this Sun. The only light source intensity is existing `scene.atmosphere.lightIntensity`, normalized irradiance E, not lux. Uniform disk radiance is E/(pi*sin(alpha)^2); displayScale is an explicit Sun-only LDR accommodation, not global exposure.

Existing 192-byte planet record and bindings 0–6 stay fixed; atmosphere record gains `sun:vec4` (angular radius, displayed radiance, glow strength, outer angle). `viewport.zw` stores atmosphere/Sun flags. `sunRadiance(direction,pixel,pixelWidth)` returns the unattenuated displayed solar term; the existing view RGB T is applied once. Halo has compact angular support, real depth clipping and a bounded 16-point estimate of visible disk area. Disk itself is tested per pixel, never gated by its center. No per-frame buffer/texture allocations.
