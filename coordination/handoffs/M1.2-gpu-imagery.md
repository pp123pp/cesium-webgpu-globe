# M1.2 GPU imagery handoff

**Result:** A04 imagery slice passes on the actual WebGPU renderer. Real bundled Natural Earth TMS imagery changes provider tiles and levels during orbit, dateline and close navigation. Geographic/Mercator mapping, polar reprojection and native layer lifecycle are verified separately with coordinate fixtures. A05/A06 remain pending.

**Files:** `WebGPUGlobeRenderer`, `WebGPUScene`, `WebGPUWidget`, `WebGPUGlobeTileProvider`; imagery renderer/browser tests and shared browser harness; CI. The separate imagery-state commit retains native skeletons, cache reference counts and parent fallback. No native WebGL renderer source changed.

## Behavior and decisions

- Default WebGPU imagery is the existing offline Natural Earth TMS (levels 0–2); `baseLayer:false` disables it and a native `ImageryLayer` can replace it. This is an actual provider/tile pyramid, with limited source resolution near the ground.
- Copy provider images into owned WebGPU textures, applying the native ImageBitmap/HTML-image flip contract. Native coordinate mappings and layer coverage drive independent aligned draw uniforms. Preserve layer alpha, show, order, removal, nearest/linear filters and per-frame provider/tile attribution.
- Keep native Mercator textures. Sample native mesh Mercator coordinates when present; calculate the missing optional coordinate or polar geographic-to-Mercator mapping when required. Never call WebGL reprojection.
- Use invariant vertex positions for equal-depth imagery overlays. Internal image boundaries are half-open so one layer blends once; terrain skirts keep their separate tolerant coverage rule. Preserve imagery-aware native `upsampledFromParent` semantics so detailed imagery can refine over upsampled terrain.
- Destroy GPU textures on final reference, cancellation, eviction and scene teardown. Late removed-layer requests cannot upload. Preserve WebGPU buffer/texture accounting and scene errors.
