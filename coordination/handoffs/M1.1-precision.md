# M1.1 — relative terrain coordinates and reversed depth

**Goal / ownership:** isolated CPU math slice on `feat/m1-globe-math`, based on accepted M0 `7a689426af4b4b5f9c510d91e68ff45623f20090`. Only `packages/engine/Source/Scene/WebGPUGlobeMath.js`, `coordination/ci/m1-globe-math.test.mjs`, and this handoff are changed. No shared renderer, Viewer, Scene, or STATUS changes.

## Interface and source evidence

- `computeRelativeViewProjection(camera, center, result = new Matrix4())` returns a native double-precision Matrix4 for RTC vertices. The caller uploads `Float32Array.from(Matrix4.toArray(result))`. Native camera/projection inputs remain unchanged; both PerspectiveFrustum and PerspectiveOffCenterFrustum retain their X/Y projection and offsets. Only finite perspective distances `0 < near < far` are supported.
- `decodeTerrainMesh(mesh)` returns `{ vertices, indices, center }`, with new Float32 vertices `[relativeX, relativeY, relativeZ, u, v, webMercatorT]` (24-byte stride), original index-array identity, and original center identity. It uses `encoding.stride`, `decodePosition`, `decodeTextureCoordinates`, and `decodeWebMercatorT` when `hasWebMercatorT`; otherwise T is V. Surface and skirt vertices survive. A default export object also satisfies Cesium's automatic index generation.
- Native camera composition is at `packages/engine/Source/Scene/Camera.js:318–331`; official RTC composition is at `GlobeSurfaceTileProvider.js:1956–1984`. TerrainEncoding's NONE/BITS12 decoder returns Earth-fixed positions (`packages/engine/Source/Core/TerrainEncoding.js:389–421`), so the center is subtracted in double precision before float32 storage.

## Depth and precision

For eye-space distance `d`, finite reversed depth is `near * (far - d) / ((far - near) * d)`. The OpenGL clip remap is `(w - z) / 2`, but it must occur **before float32 upload**. The helper sets column-major projection entries `[10] = near / (far - near)` and `[14] = near * far / (far - near)` analytically, then composes the RTC view. Use **depth32float, clear 0, compare greater**. A shader subtraction after ordinary float32 projection collapsed 20,000,000 m depth to zero in the audit; the correct value for near 0.1 / far 500,000,000 is `4.80000000096e-9`.

Tests cover 180 WGS84 samples at `(12.34567°,0°)`, `(179.9995°,85°)`, `(-179.9995°,-45°)`, and the north pole, at heights 20,000,000 / 1,000,000 / 10,000 / 100 / 1 m. Tile center is offset 750 m east and 500 m south. Every float multiply/add is rounded with Math.fround and compared with a native double reference. Maximum NDC error is **0.000182016**, at most **0.117 horizontal pixels at width 1280**. These are CPU arithmetic results, not GPU evidence; source terrain quantization remains independent of transform precision.
