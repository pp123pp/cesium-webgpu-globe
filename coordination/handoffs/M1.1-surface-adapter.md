# M1.1 surface adapter handoff

**Scope:** native CPU tile scheduling with WebGPU-owned resources; A03 integration follows in the next commit. This adapter alone is not M1 acceptance.

**Files:** `WebGPUGlobeTileProvider.js`, `m1-tile-provider.test.mjs`.

- Inherit native distance/bounding/horizon tests, geometric error, layer bookkeeping and quadtree selection. Seed the derived surface data before native bounds helpers run. Native `TerrainMesh.pick` remains available through the surface data's `renderedMesh`.
- Request real `TerrainProvider` data, retry deferred requests/mesh work, and invoke native parent upsampling for unavailable children. GPU upload is delegated after CPU mesh creation; no native WebGL resource state machine is called.
- Free buffers and imagery references during eviction/destruction; cancel pending terrain and ignore late completions. Terrain-provider replacement retires old data immediately, before the next frame. Capture the originating provider for errors.
- Parent meshes provide rectangle-limited coverage while newly selected children load. Native skirts/indices remain the renderer's responsibility.

**Verification:** `node coordination/ci/m1-tile-provider.test.mjs`: **6 passed**. Includes deferral, unavailable-child coordinates/upsampling, cancellation, idempotent eviction/reload, and provider replacement followed by late success or failure.
