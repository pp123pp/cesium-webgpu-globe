## Diagnosed failures and bounded fixes

1. The first new mountain fixture aimed its ray through a 3,310 m front slope,
   while its assertion intentionally required a >5,000 m mountain pick. The
   ray's minimum-height target changed from 3,000 to 5,500 m, keeping the same
   6,000 m provider mesh, terrain precision/SSE and strict height assertion.
   The affected remaining five groups passed, then the final eight-group gate
   passed. No terrain quality was lowered to satisfy a test.
2. Independent review found that a partially edited hidden medium array could
   shift the Sun viewport row. A regression using an empty hidden Rayleigh
   array failed before fixed-offset packing. Unused medium values now zero out
   without moving the 80-byte ABI; the same actual update test passes.
3. Bilinear source-depth visibility could borrow adjacent sky when a tiny Sun
   was completely behind a mountain. A real GPU diagnostic reproduced a zero
   disk delta but a 13/255 halo delta at a quarter-pixel phase. Requiring each
   sampled source's own depth texel to be clear removes that leak. The identical
   20-phase diagnostic passed, including all 15 fully hidden phases. The final
   gate retains five phases with the same actual mountain/depth path; every
   fully hidden disk has exactly zero added halo. Partial-disk visibility is
   still computed per fragment, not by the coarse halo estimate.

These failures are recorded as failures of earlier working trees/fixtures,
not converted into historical successes. No effective assertion or old gate
was weakened. Additional ground-horizon and low-Sun screenshot checks reuse
existing groups rather than introduce another broad suite.
