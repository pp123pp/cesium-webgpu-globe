## Decisions and residual risks

Native `IonImageryProvider.fromAssetId` caches rejected endpoint promises by
asset/options. This demo supplies no explicit access-token option, so changing
the default token does not recover a previously rejected Google endpoint. This
inherited demo limitation is **not fixed** here. The failure/retry scenario is
deliberately a real terrain metadata failure; successful Google data remains real.
No cache is cleared. The integration owner explicitly retained this bounded scope.

`M1-NAV-001` remains known unresolved. Full upstream suites and integrated M2.1
were not rerun in this worker; they require the integration checkout and latest
published head. Live service access and local certificate trust remain necessary.
