# 给后续 AI 的 M6 执行入口

本文件可直接复制给能访问仓库的 AI。用户已经确认需求和路线，并要求**下一优先阶段执行全球海洋 M6**。原 M6 的模型任务已改为 M7。

## 第一次开始：复制下面的提示词

```text
请在当前 cesium-webgpu-globe 仓库中开始下一阶段 M6 全球海洋。

先读取 AGENTS.md、coordination/STATUS.md 的当前优先级、
coordination/M6-STATUS.md、tasks/M6.md、tasks/M6/O0.md，
再读取 docs/OCEAN_PLAN.md 和当前任务相关的设计/实施计划。

本次执行 M6.O0，从 O0-01 开始，完成 O0 内可顺序推进的任务并交接。
不要重新泛泛调研或重复询问已经确定的需求。O0 要产出可核对的
基线、真实接口合同、数据路线和验收场景，不只给口头建议。
完成 O0 后报告 O1 的明确第一项；不要一次实现 O1—O7。

需求已定：保留现有 Cesium WebGPU；全球任意海域、单主相机；
近景参考 Tidewater，多尺度 FFT + 相机附近分层曲面网格；
高空保留卫星海色，允许细节渐入；环境反射为主，SSR 可选；
展示型潮汐；Cesium 时间轴统一驱动，历史泡沫允许有界重建；
先开阔海、再潮汐/近岸、完整水下最后 O7；桌面 WebGPU，
效果优先，O3/O6/O7 性能验收。

M5 未完成项如实保留，只先处理直接阻碍当前海洋任务的事项。
保持 WebGL 行为，按最小充分范围验证，禁止 SwiftShader，
遵守 docs/CI.md；不擅自 push、merge 或手动触发 Full。

结束时更新 coordination/M6-STATUS.md，报告实际修改、实际检查、
尚未验证的部分、证据和下一任务。不要将计划或只读分析写成运行通过。
```

## 后续继续：复制下面的提示词

```text
按仓库 M6 全球海洋计划继续执行。
读取 AGENTS.md、coordination/STATUS.md、coordination/M6-STATUS.md、
tasks/M6.md 和当前子阶段任务文件；核对工作区与已有证据。
从状态表中当前子阶段第一项未完成任务继续，只完成当前可审查任务
或我明确指定的同阶段任务组。沿用已确认需求，不跳到 M7，
不提前做 O7 完整水下，不把 M5 欠项标成完成。
执行必要检查并更新状态，交接实际结果、限制与准确下一项。
```

## 请求指定子阶段

可把“当前子阶段”替换为明确名称，例如 `M6.O1`。AI 应先检查它的前置是否成立；发现真实缺项时补齐与该任务直接相关的前置，不虚构通过状态，也不重新启动完整需求访谈。

## 执行约定

- 适用任意可读写仓库的 AI，不要求安装特定技能或插件。
- 数据和 GPU 的实际访问限制需要如实报告。无真实 GPU 时继续能完成的 CPU/静态/文档工作，渲染验收保持未验证。
- 技术通过、用户视觉接受、性能接受和发布分别记录。
- 一个任务出现失败时先定位，再最小范围重跑；保留失败证据。
- 不把自动 CI、手动 Full、push/merge 的既有授权规则改成默认许可。
- 计划文件的“下一阶段开始”是优先级安排；本文件本身没有预执行任何海洋代码。
